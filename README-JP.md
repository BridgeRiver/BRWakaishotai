# BRWakaishotai

An open-source Japanese handwriting font derived from Fontworks' Klee One. FontworksのKlee Oneに由来するオープンソースの日本語手書きフォント。

## プロジェクトの概要

FontworksがKlee Oneフォントをオープンソースいたしました後、霞鶩文楷GB・芫荽・芫茜雅楷など、各地の標準的な手書き字形に近いフォントが徐々に登場いたしました。Klee One自体の筆画造形は日本学参でよく使われる「教科書体」のスタイルに近いですが、その字形は印刷体に近いものとなっております。日本語学習者が日本標準の手書き字形をよりよく理解できるようにするとともに、日本のユーザーにより手書き字形に近い選択肢を提供し、この字体により広い使用シーンを持たせるために、私はその上で霞鶩文楷・霞鶩文楷GB・芫荽・Y式筆書体などの字体を参考にいたしまして、Klee Oneを可能な限り日本学参標準に近い字形に修正し、日本語教育などの用途に適したものといたしました。本書体の主な用途は日本語の組版または日本学参の手書き字形の表示でございますため、日本の主体民族を代表する「和」の字をとり、「和楷」と命名いたしました。
このフォントが携帯電話機で表示される可能性も考慮いたしまして、簡体字中国語と混在させる必要があるシーンもございますが、私はKlee Oneの文字数に基づきまして、霞鶩文楷・霞鶩文楷GBを使用してこのフォントのために通用規範漢字表の文字数を補完し、そしてこれらの字形を調整いたしまして、実際または仮想の日本の基準に従って類推することで、混在時のスタイルが統一できるようにいたしました。後期には霞鶩文楷GBなどの字を合併して文字数を拡充し続ける予定でございますが、すべてを改める計画はございません。

### 制限

- 派生フォントを作成する場合、フォント名には元のフォントの「名前を保持」を使用することはできません。本書体は名称「大桥和楷」「大橋和楷」「BRWakai」を保持し、本書体の二次派生フォントに基づいて、名称は「大橋和楷」または「BRWakai」の文字が現れてはならない、一方、フォントのソースコードを修正せずに再コンパイルしたフォントは、本フォントの保留名「大桥和楷」「大橋和楷」「BRWakai」をそのまま使用することができます。
